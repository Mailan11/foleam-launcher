# Foleam Launcher: исходный код 1.2.2

Архив предназначен для проверки работы лаунчера и самостоятельной сборки. Он не содержит аккаунтов, токенов, config.json, игровых миров, логов или доступа к хостингу. Публичный код не является гарантией отсутствия ошибок или вредоносных зависимостей.

## Сборка

Требуются Windows x64 и Node.js 24. В папке исходников выполните `npm ci`, затем `npm run dist:win -- --x64`. Результат появится в dist. Для локального запуска используйте `npm start`. Установщик не подписывается без отдельно настроенного сертификата издателя.

Публичные графические ресурсы включены для сборки интерфейса. Игровые файлы Minecraft, аккаунты и пользовательские скины не включены. Сторонние компоненты сохраняют свои лицензии, см. package-lock.json и vendor. Указание ISC в package.json не переопределяет лицензии сторонних библиотек и права на графику, Minecraft и товарные знаки.

## Что проверять

- main.js: запуск Minecraft, вход, установка Java и модов.
- account-store.js: шифрование токенов Windows DPAPI.
- launcher-updates.js: фиксированный сервер обновлений, проверка размера и SHA-256, явное подтверждение запуска.
- mailan-auth.js и streams-main.js: отдельные изолированные окна сайта и трансляций.
- scripts/prepare-installer.cjs: перед сборкой изменяет один шаблон в node_modules/app-builder-lib/templates/nsis/include/installer.nsh, удаляя ровно одну операцию копирования installer.exe. Штатная генерация деинсталлятора сохраняется. Правка повторяема после npm ci; при несовместимом изменении шаблона сборка останавливается для проверки.
- build/installer.nsh: проверка запущенного приложения без PowerShell и принудительного завершения игры.
- SECURITY.md: обзор сетевых запросов и ограничения защиты.

Команды проверок: `node test-security.cjs`, `node test-updates.cjs`, `node test-build-manager.cjs`, `node test-installer-template.cjs`.

Версии зависимостей зафиксированы в package-lock.json. Независимая сборка не обязана совпадать побайтово с опубликованным EXE из-за временных меток и особенностей инструментов. Этот архив относится к версии 1.2.2; контрольная сумма архива публикуется отдельно.
