# Foleam Launcher

Исходный код Foleam Launcher **1.2.2** для Windows x64.

[Сайт и загрузка](https://mailan1.ru/foleam.html) · [Сборка из исходников](SOURCE-README.md) · [Безопасность и сетевые обращения](SECURITY.md)

## Возможности

- Отдельные сборки Minecraft, папки модов и миров.
- Установка модов и управление скинами.
- Вход Microsoft и Mailan1 ID.
- Обновления с проверкой SHA-256 и подтверждением установки.

## Запуск

Windows x64, Node.js 24:

```sh
npm ci
npm start
```

## Установщик

```sh
npm run dist:win -- --x64
```

Результат находится в `dist`. Без сертификата издателя установщик остаётся неподписанным. Сценарий подготовки изменяет одну операцию в шаблоне NSIS; подробности в [инструкции](SOURCE-README.md).

## Проверки

```sh
node test-security.cjs
node test-updates.cjs
node test-build-manager.cjs
node test-installer-template.cjs
```
