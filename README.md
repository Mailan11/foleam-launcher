# Foleam Launcher

Исходный код Foleam Launcher **1.3.0** для Windows x64.

[Сайт и загрузка](https://mailan1.ru/foleam.html) · [Сборка из исходников](SOURCE-README.md) · [Безопасность и сетевые обращения](SECURITY.md)

## Возможности

- Отдельные сборки Minecraft, папки модов и миров.
- Установка модов и управление скинами.
- Вход Microsoft и Mailan1 ID.
- Обновления с проверкой SHA-256 и подтверждением установки.
- Дополнение Foleam Voice: лобби до 8 участников, приглашения по ссылке и коду, микрофон и громкость.
- Скачивание, отключение и удаление дополнения в настройках.

## Запуск

Windows x64, Node.js 24:

```sh
npm ci
npm start
```

## Установщик

```sh
npm run dist:win -- --x64
```

Результат находится в `dist`. Без сертификата издателя установщик остаётся неподписанным. Сценарий подготовки изменяет одну операцию в шаблоне NSIS; подробности в [инструкции](SOURCE-README.md).

## Проверки

```sh
node test-security.cjs
node test-updates.cjs
node test-build-manager.cjs
node test-installer-template.cjs
node scripts/package-voice.cjs
node test-addons.cjs
```

Публикация кода не является независимым аудитом или гарантией безопасности. В репозитории нет аккаунтов, токенов, игровых данных и доступа к серверу. `SOURCE-SHA256.txt` содержит контрольные суммы файлов исходного архива 1.3.0; README и .gitignore добавлены для GitHub отдельно.

Клиент дополнения: `voice-client`. Серверный модуль и требования: [voice-server/README.md](voice-server/README.md). Полный сервер Mailan1, база данных и секреты в репозиторий не включены.
